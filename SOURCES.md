# Sources — buybacks-vs-dividends

All figures are from S&P Dow Jones Indices' S&P 500 buyback/dividend
reports (calendar-year $ billions), as published via PR Newswire:

- 2015-2018: "S&P 500 Q4 2018 Buybacks Set 4th Consecutive Quarterly
  Record at $223 Billion; 2018 Sets Record $806 Billion" (S&P DJI, via
  PR Newswire, published 2019-03-19). Table gives 2014-2018 annual
  dividends, buybacks, operating earnings, market value.
- 2018-2024: "S&P 500 Q2 2025 Buybacks Decline 20% Amidst Uncertainty to
  $235 Billion From Q1 2025's Record $293 Billion" (S&P DJI, via
  PR Newswire, published 2025-09-25, republished by Nasdaq). Table gives
  2018-2024 annual dividends, buybacks, operating earnings, market
  value, plus 12-month rolling rows used as cross-checks.

Notes:
- Where the two tables overlap (2018), the later vintage is used
  (operating earnings $1,281.66B; the 2019 release's $1,281.83B was
  preliminary).
- 2025 rolling 12-month figures exist but 2025 is not a completed
  calendar year, so the analysis uses completed calendar years 2015-2024
  (10 years).
- FRED series SP500 (daily index close) is fetched only as a
  connectivity sanity check; payout numbers do not come from FRED.
